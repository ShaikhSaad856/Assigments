Decendent Combinator:-

A descendant combinator in CSS is represented by a single space character ( ) between two selectors.

It selects any element that is nested inside a specified ancestor element (such as a child, grandchild, or deeper).


Child Combinator:-

selects only the elements that are immediate, direct children of a specified parent element its specify by (>)

It excludes grandchildren or any deeper nested descendants.
